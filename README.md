# 📚 AI Reading Assistant (Phase 1 – Transcription & Playback)

This project is an AI-powered reading assistant designed to help children improve pronunciation and reading fluency. It is currently in **Phase 1**, which focuses on:

✅ Playing a Panchatantra story  
✅ Recording the child's voice line-by-line  
✅ Transcribing speech using [Faster-Whisper](https://github.com/guillaumekln/faster-whisper)  
✅ Displaying original vs. transcribed text on a frontend
